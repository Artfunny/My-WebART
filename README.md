# My WebArt

**PNG to WEBP · Kit builder**

A public, generic 2D art vault for converting PNG (and other stills) to WebP, sorting by category, and packing a kit zip.

This is a standalone version of the 2D art vault. It does **not** share browser storage with ARTfunny ARTwork.

- localStorage key: `my-webart-library-v1`
- IndexedDB name: `my-webart-artwork`

## How to use

1. Drop files or a folder onto the page (or use Files / Folder).
2. Confirm categories and convert — stills become WebP (PNG kept as original).
3. Tick pieces into a kit.
4. Download the zip.

See the in-app **How to use** page in the menu.

## Notes

- One lightweight example asset is shipped per category so the app stays quick to load.
- Video and docs keep their original formats.
- Branding is generic for public sharing on X.
- Sign-in is off. Libraries live in this browser only.
